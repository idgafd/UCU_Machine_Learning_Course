# UCU_Machine_Learning_Course

Structure:

- Final_Project — Parameter-efficient Particle Transformer (ParT) for LHC jet tagging (shared weights + weighted layer decoders); includes the final report and presentation.
- Assignment_1 (HW1) — Supervised learning: implement KNN (MNIST), evaluate accuracy, analyze misclassified examples; explore a provided model artifact; apply K-fold cross-validation for model selection on a regression task (NYC taxi-style tabular data with tree-based models).
- Assignment_2 (HW2) — Unsupervised learning: PCA on MNIST (variance–dimension trade-off + visualization) and downstream classification (logistic regression); nonlinear feature mapping to increase separability (paraboloid projection); clustering model selection using the Silhouette method (plus additional clustering/embedding explorations).
- Assignment_3 (HW3) — Deep Learning: implement a 3-layer neural network from scratch (forward + backprop + training + visualization); modify a CNN in Keras by removing/adding convolutional blocks and compare learning curves; build a custom dataset and train a CNN using the fast.ai API.
- Assignment_4 (HW4) — Regularisation: compare Linear vs Ridge vs Lasso vs ElasticNet and interpret coefficients; tune dropout via validation/CV and retrain with the best rate; design a stronger data augmentation pipeline for CIFAR-10 and evaluate improvements.
- Assignment_5 (HW5) — Ensembles: implement bagging manually (multiple KNN estimators + majority vote) and reproduce with sklearn BaggingClassifier; train and evaluate XGBoost (MNIST) and compare with classic boosting methods; implement blending with a meta-learner (SVM) using predicted probabilities.
- Assignment_6 (HW6) — Performance metrics: compute precision/recall/F1 from scratch (including macro and weighted averages) on an imbalanced dataset and verify vs sklearn; compare models using Precision–Recall curves; build Voting and Stacking ensembles and compare PR performance against individual models.
